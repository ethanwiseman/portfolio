**Tool:** MATLAB  
**Focus:** Engineering computation and numerical approximation

## Overview

Coursework and programming exercises explored how numerical methods approximate engineering solutions and how algorithm choices affect accuracy.

## Work covered

| Topic | Method or exercise | Engineering purpose |
| --- | --- | --- |
| Numerical integration | Euler method for rocket motion | Compare a numerical trajectory with an analytical solution |
| Time-step sensitivity | Steps of 60, 30, 15, and 5 seconds | Examine how step size affects approximation error |
| Numerical differentiation | Finite differences | Estimate derivatives from sampled values |
| Root finding | Newton's method | Solve nonlinear equations iteratively |
| Linear systems | Gaussian elimination | Solve coupled algebraic equations |
| Optimization | Gradient descent | Explore iterative minimization |
| Series approximation | Taylor series | Approximate functions locally |

## Engineering reasoning

An algorithm returning a value does not establish that the value is accurate. Comparison with analytical solutions and examination of step-size effects provide a basis for evaluating numerical behavior.
